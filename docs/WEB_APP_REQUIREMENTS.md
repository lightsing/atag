# ATAG 网页需求（当前）

更新：2026-11-08。用户数据由浏览器拥有；Agent 只提供 Anisette 与限定 Apple endpoint 的字节转发。没有演示数据源、模拟 Tag、假坐标或演示切换。

## 数据与离线能力

- 唯一工作区是此站点的 IndexedDB，保存设备昵称/图标/颜色、Tag 私钥/seed、芯片身份、建档轮换周期、已绑定 Tag 的最近运行周期和轮次、查询设置及历史报告。
- 页面默认空状态；无 Agent 和 Apple 登录也能生成密钥档案、编辑设备、读取已存历史、备份与恢复。存储失败明确报错，不用内存冒充已保存。
- 新密钥在浏览器 CSPRNG 生成并先存储；草稿不代表 Tag 已配置。从相同档案可重建相同 104-byte 配置，关闭页面/恢复备份后不需要重新生成私钥。
- 档案昵称与 Tag 名称分开；只有读到芯片序列号且用户确认写入的已知档案才绑定，不按浏览器 ID 或名称猜测。

## Apple 账号

- 网页连接本地桥接后，用户在设置中填写 Apple 账号和密码，选择受信任设备或短信，再发送并填写验证码。
- 浏览器计算 SRP 证明并验证 Apple M2 后解密 SPD；二次验证后重新 SRP，取得 delegate 查询会话。Agent 不处理密码、不持有 challenge、账户或登录业务状态。
- 密码仅保留在当前设置页内存中；超时、网络失败、验证码错误、验证过期和账户处理要求不清空密码，用户可直接重试。Apple 明确拒绝账户/密码、登录成功、取消或关闭设置时清空。验证码提交后清空；密码和验证码不进入 URL、日志、偏好或备份。最终 query session 仅在完整成功且本地提交后保存。
- 支持待处理、选择方式、重发、换方式、错误密码/验证码、过期、取消、完成和退出登录；最多 5 次发送、3 次提交，10 分钟生命周期。
- 重复点击被锁定；关闭设置/卸载/断开桥接取消未完成流程。迟到响应不再请求或提交会话。失败/取消不覆盖原登录；退出只移除登录会话，保留设备和历史。
- 没有终端 login 或独立账号会话文件导入入口。加密备份可由用户选择包含最终 query session，从不包含临时认证材料。

## 桥接与报告

- 网页打开时自动探测本地桥接，通过健康和能力检查后连接。探测失败时可以重试或手动输入 loopback 地址。连接可取消和断开，无需访问令牌。
- 桥接只提供 /v1/anisette 与 /v1/apple/request；客户端检查 anisette 与 appleRelay 能力。
- 账号、SRP、验证码和报告业务逻辑在浏览器；桥接固定 URL/方法、限制请求头与大小、不跟随重定向。Anisette 提供方不收到 Apple 凭据。
- 网页下载 Find My 原始密文、认证解密、验证坐标和时间、去重并原子持久化。无新报告是成功；报告新鲜度、BLE 连接和桥接状态分别显示。
- 保留设备搜索/排序、地图选择、精度范围、24h/7d 历史、完整分页、元数据编辑和删除确认。报告电池电压按 2.4–4.2 V 六位编码解析，不当作当前值，不换算百分比。
- 轮换报告认证解密后保存命中的密钥轮次；旧报告重新命中时补全轮次。自动模式按最近报告或已绑定 Tag 的遥测和轮换周期估算最近 7 天的范围，为轮次边界和断电停转留余量。没有轮次依据时沿用已保存范围；用户可切换手动查询。

## 附近管理

- 仅真实 Web Bluetooth；不支持时如实提示，仍允许离线生成档案与备份。
- 按固件服务发现随机名称；连接先公开信息，按键计数基线不当按键，收到变化可辨认设备，不延长连接时限。
- 受保护操作先配对，0009 只有状态 2 才放行。标准 2a25 被浏览器屏蔽，序列号从加密遥测取得。
- 支持身份/电压/遥测、UTF-8 名称、固件设置、配置密钥、重启和恢复出厂；可选 LED 查找和按键辨认。
- 名称最多 29 UTF-8 字节；设置严格按固件格式、CRC、字段范围和保留位处理。
- 保存只认本次匹配的新 Flash commit 通知；ATT 响应、旧回执或断连都不算成功。commit 后断开仍显示成功，回执前断连为未知。
- 连接时限从原连接建立时计算，按键不延长；保存较短时限可能提交后立刻断开。广播窗口等参数下次窗口生效。
- 密钥写入成功后重启广播，以后短按管理，不需要恢复出厂；重启/恢复出厂命令没有完成回执，需重连核验。

## 固件升级

- 在附近管理导入已签名的 `.atag-ota` 应用包。网页用固件对应的公钥验证 Ed25519 签名，校验目标、分区、镜像长度、启动向量和 SHA-256。包留在当前浏览器会话。
- 直接使用公开的 OTA GATT 特征。旧固件缺少特征时仍可连接管理。升级前检查引导程序、容量和电池电压。
- 发送 DIGEST、BEGIN、顺序数据块和 FINISH，等待设备确认后才推进。进度来自 Flash 已确认偏移。上传可在 FINISH 前取消，断线后可重连并重新上传。
- 区分设备确认安装排程、尚未核验和重启核验结果。重连同一蓝牙设备后核对版本、配置摘要、密钥模式与轮次；同版本不宣称已验证到新镜像。

## v0.1.0 可选 LED

- `has_led` 只来自硬件遥测，未读取时为未知；网页不写出厂标志。没有 LED 的硬件禁用权限开关与查找，保留按键辨认。
- `led_enabled` 默认关闭。设置包仍为 64 字节 v1，byte 1 bit 0 保存开关，CRC32 覆盖前 60 字节；其余保留位为零。
- 连接且已加密、遥测确认有 LED、设备已保存开关开启，才允许闪灯 10 秒。未保存草稿不放行；单独提供停止按钮，停止不要求权限仍开启。
- CONTROL 3/4 分别等待本次新状态 7/8；两者成功但均不表示 Flash 提交。状态 9 是拒绝，区分无硬件、未启用、OTA 忙。LED 回执不完成设置保存，开始/停止回执不能互相替代；ATT 确认、旧状态、超时与断连都不冒充成功。
- LED 指令结果与设置保存结果分别展示；设备不报告实时灯态，只展示指令确认和明确标记的时间推算。保存关闭、断开连接、开始 OTA 或满 10 秒由固件停止，不延长管理连接。
- BLE 由网页直接处理，本次不增加本地 Agent 职责。新板实物闪烁仍需硬件验证。

## 文件与备份

- 版本化密码加密备份包括设备元数据、Tag 主私钥/seed、芯片绑定、查询设置和历史。AES-256-GCM + PBKDF2-SHA256，随机 salt/nonce；密码至少 8 字符，用户输入两次。
- 默认不包含 Apple query session，用户可勾选；密码、验证码和临时认证材料永不包含。
- 恢复先选文件和密码，解密预览设备/报告数量，再明确确认合并。完整认证与结构校验通过才原子提交；错误密码、损坏、未知版本、密钥/序列号冲突整体拒绝，当前数据不变。
- 重复恢复不重复记录，现有昵称与查询设置优先。仅接受当前 schema 1，未知版本整体拒绝。
- 清除站点数据或换浏览器需要备份迁移；IndexedDB 没有额外应用密码锁，备份文件有密码认证保护。普通显示偏好和连接地址保存在 localStorage，不属于当前备份。

完整桥接边界见 [LOCAL_AGENT_API.md](LOCAL_AGENT_API.md)。
